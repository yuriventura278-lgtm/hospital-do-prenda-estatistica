Bem-vindo

Sobre esta Aplicação

Este módulo de Controlo de Pacientes — UCI faz parte do ZELO — Sistema Estatístico e Gestão de Ocorrências do Hospital do Prenda.

Desenvolvimento pelo Serviço de Admissão e Arquivo Médico Estatístico.

Funcionalidades Principais

Internados: Visualize, procure e gerencie pacientes atualmente internados no hospital.

Registar Paciente: Adicione novos pacientes com dados completos de admissão.

Registar Saída: Registre saídas (altas, óbitos, transferências) com documentação apropriada.

Relatórios: Gere relatórios mensais com estatísticas e exportação para PDF.

Como Usar

1. Use os botões na barra superior para adicionar pacientes ou registar saídas.

2. Procure pacientes usando a barra de pesquisa.

3. Aceda aos relatórios mensais para análise de dados.

4. Os dados ficam guardados neste dispositivo e são sincronizados com o servidor do ZELO, para aparecerem nos outros computadores do serviço.

Dados e Privacidade

Só utilizadores com sessão iniciada no ZELO e com acesso a este sistema podem ver estes registos. Continuam também guardados neste dispositivo, para funcionar sem internet.
