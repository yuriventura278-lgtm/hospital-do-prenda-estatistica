ZELO — Pasta de Backup Protegida (Windows)
============================================

O que isto é
------------
Dois scripts para Windows que criam, em cada computador do hospital, uma
pasta dedicada aos backups automáticos do ZELO com:

  - Ícone próprio (cadeado), para se distinguir de uma pasta normal;
  - Protecção contra eliminação — contas Windows "Padrão" não conseguem
    apagar a pasta nem o que está lá dentro (o Windows recusa, com "Acesso
    negado"), mesmo sem querer, pela Reciclagem ou de outra forma;
  - Ocultação da navegação normal do Explorador, para não aparecer
    à vista de qualquer pessoa que abra "Este Computador";
  - Um atalho "Abrir Backup ZELO" no ambiente de trabalho que pede um
    código antes de mostrar o conteúdo da pasta.

Importante ser honesto sobre os limites
----------------------------------------
O Windows não tem uma função nativa de "pasta com palavra-passe" (isso só
existe com BitLocker a cifrar o disco inteiro, ou software de terceiros).
O que este conjunto de scripts oferece é o equivalente prático mais
próximo, usando só ferramentas do próprio Windows:

  - A eliminação é IMPEDIDA de verdade ao nível do sistema (permissões
    NTFS) — isto é uma protecção real, não apenas visual.
  - O "código de acesso" ao abrir a pasta é uma barreira de conveniência
    (evita que alguém tropece na pasta e a abra por engano) — não é
    encriptação. Alguém com conhecimentos avançados e conta de
    Administrador consegue sempre contornar isto, tal como consegue
    contornar qualquer protecção baseada em permissões do Windows.
  - Para a protecção fazer sentido, os computadores do hospital devem
    ter os funcionários a usar contas Windows "Padrão" (não
    Administrador) no dia-a-dia — só a conta de Administrador (a de TI)
    deve conseguir desfazer isto.

Como instalar (uma vez por computador)
---------------------------------------
1. Copia a pasta "pasta_backup_protegida" (com os 2 ficheiros .ps1) para
   o computador, por exemplo para o Ambiente de Trabalho.
2. Clica com o botão direito em "Instalar_Pasta_Backup_Protegida.ps1" e
   escolhe "Executar com o PowerShell". Se aparecer um aviso do
   Controlo de Conta de Utilizador, escolhe "Sim" (o script precisa de
   privilégios de Administrador só durante a instalação).
3. Segue as perguntas no ecrã:
     - Caminho da pasta (Enter para aceitar o sugerido); ou o caminho de outra
     - Código de acesso (define e confirma).
4. No fim aparece o caminho completo da pasta criada — guarda-o.

Como ligar a pasta ao sistema ZELO
------------------------------------
1. Abre qualquer página do ZELO e clica no botão de Backup Automático,
   no cabeçalho, e depois em "Escolher pasta".
2. Como a pasta está oculta, pode não aparecer se navegares clicando
   pastas normalmente no selector do navegador — em vez disso, cola o
   caminho completo (mostrado no fim da instalação) na barra de endereço
   da janela do selector e prime Enter, depois confirma a selecção.
3. A partir daí o ZELO grava sozinho nessa pasta, organizado por
   página e por período (Diário/Semanal/Mensal/Trimestral/...), sem
   mais nada a fazer.

Como abrir a pasta mais tarde (para copiar para uma pen, por exemplo)
-------------------------------------------------------------------------
Usa o atalho "Abrir Backup ZELO" no ambiente de trabalho. Vai pedir o
código definido na instalação e depois abre a pasta no Explorador.

Se precisares de repetir a instalação (mudar de pasta ou de código)
---------------------------------------------------------------------
Corre "Instalar_Pasta_Backup_Protegida.ps1" outra vez como Administrador
— substitui a configuração anterior neste computador.

Como isto foi validado
-------------------------
Estes scripts foram escritos e revistos com cuidado, mas NÃO foram
corridos numa máquina Windows real — o ambiente onde foram desenvolvidos
não tem acesso a Windows para testar. A sintaxe do PowerShell e do
"icacls" (o comando que aplica a protecção contra eliminação) foi
verificada contra a documentação oficial da Microsoft, e a lógica foi
revista várias vezes à procura de erros — incluindo uma correcção
importante: a primeira versão negava "Apagar" ao grupo "Utilizadores",
mas numa conta de Administrador local (fora de um domínio) o Windows
não a remove do grupo "Utilizadores" ao torná-la Administrador — ficaria
nos dois grupos ao mesmo tempo, e uma permissão "Negar" aplica-se sempre,
por isso isso teria bloqueado também a própria conta de TI. A versão
actual evita este problema concedendo aos "Utilizadores" só as
permissões de ler/criar/escrever (sem "Apagar"), em vez de negar
explicitamente — assim uma conta de Administrador continua a conseguir
remover a protecção quando for mesmo preciso.

Recomendação: antes de instalar nos computadores do hospital, testa
primeiro num único computador (ou numa máquina virtual Windows) que não
seja crítico, confirmando que:
  1. A pasta fica visível e com o ícone certo (se a "ocultares" de novo,
     confirma primeiro que o ícone aparece antes de esconder);
  2. Uma conta Windows "Padrão" não consegue apagar a pasta nem o que
     está lá dentro (tenta apagar — deve dar "Acesso negado");
  3. A conta de Administrador CONSEGUE apagar, se for preciso desfazer;
  4. O atalho "Abrir Backup ZELO" pede o código e abre a pasta certa;
  5. O botão "Escolher pasta" do ZELO consegue mesmo escrever ali.
Se algum destes passos falhar, por favor reporta o erro exacto (a
mensagem do PowerShell) para eu poder corrigir.
