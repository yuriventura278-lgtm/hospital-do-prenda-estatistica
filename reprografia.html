Cópia de segurança automática

⚠️ Este navegador não suporta a escolha automática de pasta. A cópia automática fica indisponível — recomenda-se exportar manualmente (secção "Exportar dados" abaixo) com regularidade, por exemplo no fim de cada dia.
Nenhuma pasta configurada.

Escolha uma pasta no computador (ex: um disco partilhado) onde o sistema grava automaticamente uma cópia dos dados sempre que houver uma alteração. Funciona apenas em navegadores baseados em Chromium (Chrome / Edge).

Exportar dados

Guarde uma cópia completa a qualquer momento, independentemente do navegador.

Restaurar cópia

Importe um ficheiro JSON exportado anteriormente. Os registos existentes não são apagados — apenas são adicionados/atualizados os que vierem no ficheiro.

Estado do armazenamento

Os dados são gravados em duas camadas no próprio dispositivo (IndexedDB + cópia local), para nunca se perderem mesmo que uma delas falhe. Ainda assim, recomenda-se exportar regularmente.
